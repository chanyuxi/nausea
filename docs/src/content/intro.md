# Nausea

Nausea is a toolkit for composing high-availability preset components from popular industry tooling.

## Packages

- `@nausea/table` provides the table component entry.
- `@nausea/options-dispatcher` provides the options dispatcher entry.

## Workflow

Use the workspace scripts from the repository root:

```sh
pnpm build
pnpm build:docs
pnpm docs:dev
```
